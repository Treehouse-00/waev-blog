## Notes

- **SD-10 rule wording.** Every tag CollectionPage carries a valid `hasPart`
  array of `BlogPosting` entries enumerating exactly the tagged posts (name +
  canonical `url` present). The playbook's SD-10 `Check` phrases the enumeration
  as a `mainEntity`/`hasPart` **`ItemList`**; the implementation uses a
  `hasPart` array directly, which is schema.org-valid and satisfies the
  enumeration intent. Scored PASS. Consider tightening the SD-10 wording to
  accept "`hasPart` array of `CreativeWork`" so future sweeps don't read this as
  a near-miss.
- **Rules not scored this sweep.** SD-02 (dateModified) and MT-06 modified-time
  consistency depend on frontmatter `updated`, which the built HTML does not
  expose without re-parsing source; HP-04, IL-05, SM-05, and TG-02/TG-03/TG-05
  are stylistic/editorial checks outside the weekly link-and-crawl remit. None
  showed any incidental signal of failure during the crawl. They are covered by
  the monthly full audit (§3.6).
- **No fix PR from this sweep.** The two open findings are both tracked
  editorial work (MT-02 → PR #86 + one new post; IL-02 → issue #85). The weekly
  sweep found no *safe mechanical* fix of the broken-internal-link class that
  would warrant its own PR, so per §3.3 none was opened. This report (gate:
  `none`) is the sweep's deliverable.
